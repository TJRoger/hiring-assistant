  介绍：AI Hiring Assistant

  AI Hiring Assistant 是一款基于 Claude AI
  的开源招聘助手，将简历筛选、面试问题生成、候选人综合评分集成于一体，让招聘团队从
  繁琐的重复劳动中解放出来，专注于真正重要的事——判断人。

  ▎ GitHub 地址：AI Hiring Assistant

  ---
  它能做什么？

  1. 智能简历评估，秒出匹配分

  上传候选人简历文本，AI 自动对照岗位要求进行多维度分析，输出结构化评分报告。不再依
  赖"感觉不错"，每一个决策都有数据支撑。

  2. 为每位候选人量身定制面试问题

  不同候选人，不同背景，问题应该有所不同。系统根据岗位描述和候选人简历，自动生成针
  对性的面试问题，让每场面试都直击要害。

  3. 实时追问，深挖候选人真实能力

  面试过程中，AI 分析候选人的回答，智能生成追问建议，帮助面试官把"表面漂亮的回答"和
  "真正有深度的思考"区分开来。

  4. 全维度候选人评分

  面试结束后，系统从技术能力、工作经验、沟通表达、文化契合度四个维度出具综合评分报
  告，为最终 Offer 决策提供客观依据。

  ---
  快速上手，5 分钟跑起来

  git clone https://github.com/rogerluo410/hiring-assistant
  cd hiring-assistant
  npm install
  cp .env.example .env       # 填入 Anthropic API Key
  cp config/users.example.json config/users.json
  npm run dev:full

  打开 http://localhost:5173，即刻体验。

  支持 Docker 一键部署，也可以直接推送到 Vercel 完成云端上线，零运维负担。

  ---
  技术栈一览

  - 前端：React 18 + Vite + Tailwind CSS
  - 后端：Express（API 安全代理）
  - AI 引擎：Anthropic Claude（claude-sonnet）
  - 数据：本地 LocalStorage，隐私优先
